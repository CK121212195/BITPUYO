# 🧩 BITPUYO

フィアットのブロックを消し去り、Satsを積み上げるためのWebパズルゲームです。

## 📝 概要
ブラウザで手軽に遊べるビットコインテーマの落ち物パズルゲームです。落ちてくるブロックを戦略的に並べて連鎖を狙い、画面をクリーンに保ちます。インフレの波に飲み込まれず、最高スコアを目指してください。

## 🚀 特徴
- 🪙 ビットコインの世界観をベースにしたUI/UX
- 🛡️ 完全にクリーンなオープンソースコード（広告・トラッカーなし）
- ⚡ PC・スマホのブラウザで即座にプレイ可能
