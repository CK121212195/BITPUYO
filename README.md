# 🧩 BITPUYO

**「フィアット（法定通貨）のブロックを消し去り、サトシ（Sats）を積み上げろ！」**  
往年の名作落ち物パズルとビットコインのカルチャーが融合した、中毒性抜群のWebゲームです。

## 🌟 概要
BITPUYOは、ブラウザで手軽に遊べるビットコインテーマのパズルゲームです。落ちてくるブロックを戦略的に並べて連鎖を狙い、画面をクリーンに保ちましょう。落ちてくるフィアットの波に飲み込まれず、最高スコア（HODLパワー）を目指してください！

## 🚀 特徴
- **Bitcoin Aesthetics:** ビットコインの世界観に染まったクールなUI/UX。
- **ストレス解消＆HODL訓練:** 連鎖を決めて、日々の市場のノイズを吹き飛ばしましょう。
- **完全無料・オープンソース:** 広告なし、トラッカーなし。純粋なクリーンコード。
